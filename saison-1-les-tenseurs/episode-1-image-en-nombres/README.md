# Épisode 1 — De l'image à la donnée numérique

Le chiffre 7 de la série, lu depuis `matrice_8x8.csv` : 8 lignes, 8 colonnes, 64 nombres entre 0 (noir) et 255 (blanc). Le script affiche la matrice, puis la redessine avec des caractères pour montrer que ces nombres suffisent à reconstituer l'image.

```bash
python image_en_nombres.py
```
